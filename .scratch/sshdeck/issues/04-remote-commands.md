# 04：依主機別名執行遠端命令

Status: ready-for-agent
Blocked by: 02

## What to build

使用者可在 CLI 與前端指定主機別名執行遠端命令，即時查看輸出與結束狀態，並在不同主機同時執行各自工作。

前置：02「既有金鑰登入與主機信任」。規格：[sshdeck spec](../spec.md)。涵蓋 User Stories 22、24–25 及命令取消相關行為。

## Acceptance criteria

- [ ] `sshdeck exec <別名> -- <命令>` 與前端命令入口可在指定受管主機、以設定的登入帳號執行命令，操作清楚標示目標身分。
- [ ] 命令執行沿用既有解鎖及主機信任規則，不繞過首次核對或指紋衝突處理。
- [ ] 工作進行期間即可收到輸出；命令完成呈現結束狀態，CLI 能反映遠端命令失敗，與連線／認證失敗清楚區分。
- [ ] 文件定義 CLI 引數、引號、空白及特殊字元的遠端解讀方式；遠端命令不得意外在本機執行。
- [ ] 兩台主機可同時執行命令，輸出、登入身分及取消狀態不混用；一台失敗不終止另一台工作。
- [ ] 使用者可中斷操作；工作完成、取消、斷線或服務停止均清理相應本機資源，不宣稱已停止所有遠端衍生程序。
- [ ] 斷線時顯示失敗狀態，不自動重送可能具有副作用的命令。
- [ ] 經 CLI 與瀏覽器驗證串流輸出、非零結束狀態、連線中斷、取消與雙主機隔離；建立可於三平台重用的命令引用案例。

## Verification notes

使用可控制的 SSH 測試環境與專用測試命令。完整互動程式由 05 處理，此票不以單次命令介面冒充互動終端機。
