# 05：CLI 與瀏覽器互動終端機

Status: ready-for-agent
Blocked by: 02

## What to build

使用者透過 CLI 或瀏覽器開啟指定主機的完整互動 shell，可連續輸入、操作互動程式、調整終端機尺寸，並同時操作不同主機。

前置：02「既有金鑰登入與主機信任」。規格：[sshdeck spec](../spec.md)。涵蓋 User Stories 23–26。

## Acceptance criteria

- [ ] `sshdeck shell <別名>` 與前端終端機皆可建立真正的互動 SSH 終端機工作階段，清楚顯示主機別名及登入帳號。
- [ ] 終端機沿用共用密語解鎖及主機信任規則；前端手動鎖定解鎖快取不被誤報為已終止既有工作階段。
- [ ] 支援連續輸入、即時輸出、終端機尺寸變更及互動程式；CLI 結束或失敗後還原本機終端機狀態。
- [ ] 不同主機可同時存在獨立工作階段，輸入、輸出及關閉操作不交叉影響。
- [ ] 關閉終端機、相關瀏覽器頁面或本機服務時釋放相應 SSH 連線與本機資源。
- [ ] 斷線顯示原因及結束狀態；重新開啟是新工作階段，不恢復原終端機或靜默重播輸入。
- [ ] 使用者可中斷前景操作或結束工作階段；文件說明連線結束不保證遠端衍生程序停止，持久容器應使用 Docker 背景模式。
- [ ] 瀏覽器終端機連線遵守本機存取與跨來源邊界，不能僅因使用串流連線就繞過本機服務的限制。
- [ ] 經 CLI 與瀏覽器驗證互動輸入、尺寸變更、互動程式、雙主機隔離、斷線及關閉清理，提供三平台可執行的驗證方式。

## Verification notes

可直接使用既有金鑰與已授權測試主機驗收，不依賴 03、04 的金鑰生成或單次命令入口。
