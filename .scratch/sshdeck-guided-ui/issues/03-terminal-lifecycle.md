# 03 — 整合互動終端機與主機切換生命週期

Status: ready-for-agent
Type: task
Blocked by: 01
Spec: [SSH 主機操作介面與逐步建立指南](../spec.md)

## 目標與範圍

主機操作頁一次提供一台受管主機的互動終端機，沿用現有 shell、WebSocket 與 xterm.js 能力。終端連線狀態與 SSH 檢查結果分開。

使用者已確認：切換主機有活躍連線時先確認；只切換左側分頁保留連線。重新整理頁面不承諾恢復原終端連線。

## 驗收條件

- [ ] 選取主機後須按「連線」才開啟，提供「中斷」與未連線／連線中／已連線／已中斷回饋。
- [ ] 活躍終端連線由 A 切到 B 時提示將中斷，可取消；取消保留 A 的選取與連線。
- [ ] 確認後中斷 A 並切到 B，B 須主動連線，不同時留下兩個互動工作階段。
- [ ] 連線建立中切換、延遲輸出與關閉事件不會串到 B；輸入永遠只傳給目前有效的目標。
- [ ] 切換到建立指南再返回時，同一主機的終端連線與輸出仍保留。
- [ ] 列表刷新與檢查更新不重建終端機；回到分頁或調整視窗後尺寸正確。
- [ ] 中斷或連線失敗可再次連線，相關資源與事件監聽會清理。
- [ ] 中斷提示不保證遠端所有程序都會停止。

## 驗證

驗證確認／取消、連線建立中的切換、舊輸出隔離、重新連線、分頁來回與視窗縮放。以兩個可辨識的測試目標或替身確認輸入及輸出不跨主機。
