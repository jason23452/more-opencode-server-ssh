# 06 — 整合進階管理與既有主機／金鑰操作

Status: ready-for-agent
Type: task
Blocked by: 02, 03, 05
Spec: [SSH 主機操作介面與逐步建立指南](../spec.md)

## 目標與範圍

把非首次連線所需的內容移至選定受管主機的進階入口，保留既有能力，並與檢查失效、指南進度與終端生命週期整合。

## 驗收條件

- [ ] 進階入口提供 Docker 檢查／權限指南、撤銷公鑰指南與單次遠端命令。
- [ ] 可找到編輯／刪除主機、檢視公鑰、刪除受管理金鑰及解除既有金鑰關聯入口。
- [ ] 操作明示目標主機與帳號，單次命令保留輸出與取消能力，不與互動終端機混淆。
- [ ] 本機金鑰刪除、既有金鑰解除關聯與遠端撤銷授權分開說明，保留原有確認與管理邊界。
- [ ] Docker 操作不改變指南以 SSH 成功為完成條件的規則。
- [ ] 編輯主機或變更金鑰後同步使檢查與指南完成狀態失效；刪除後清除過期選取與對應進度。
- [ ] 刪除或修改操作不使原終端機被誤認為新目標／新設定的連線；必要時中斷原連線並明確回饋。
- [ ] 進階指南可複製且長內容不造成整頁橫向溢出，授權與撤銷仍為手動遠端操作。

## 驗證

對既有主機／金鑰管理、Docker、單次命令串流與取消進行回歸；驗證有活躍終端或進行中檢查時修改／刪除目標，以及返回指南後的狀態一致性。
