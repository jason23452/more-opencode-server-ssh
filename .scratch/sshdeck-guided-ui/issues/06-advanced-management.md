# 06 — 整合進階管理與既有主機／金鑰操作

Status: ready-for-agent
Type: task
Blocked by: 02, 03, 05
Spec: [SSH 主機操作介面與逐步建立指南](../spec.md)

## 目標與範圍

把非首次連線所需的內容移至選定受管主機的進階入口，保留既有能力，並與檢查失效、指南進度與終端生命週期整合。

## 驗收條件

- [x] 選定主機的進階入口提供 SSH／Docker 檢查、含 Docker 權限與撤銷說明的公鑰指南，以及單次遠端命令。
- [x] 編輯／刪除受管主機、檢視公鑰、刪除本機受管理金鑰及解除關聯入口集中在選定主機；全域管理金鑰清單另可找到。
- [x] 進階操作標示所選主機與登入帳號；單次命令鎖定所選目標、保留串流輸出與取消，且不與互動終端區混淆。
- [x] 本機金鑰刪除、主機關聯解除與遠端撤銷授權維持不同操作及確認；解除關聯不刪本機私鑰，刪除本機私鑰不聲稱遠端授權已撤銷。
- [x] Docker 檢查只在明確進階檢查中執行，不改變指南以 SSH 成功為完成條件。
- [x] 編輯／刪除主機和變更金鑰透過既有 hostschange/status profile hooks 使檢查、指南狀態失效；刪除清除目前選取及該主機指南進度。
- [x] 選定主機編輯／刪除時由 03 終端模組按連線設定變更／刪除中斷終端，明確回饋且不沿用舊目標。
- [x] 進階授權／撤銷指南沿用複製按鈕及長內容區域捲動；授權與撤銷仍為使用者在遠端 Linux 主機手動執行。

## 驗證

對既有主機／金鑰管理、Docker、單次命令串流與取消進行回歸；驗證有活躍終端或進行中檢查時修改／刪除目標，以及返回指南後的狀態一致性。
