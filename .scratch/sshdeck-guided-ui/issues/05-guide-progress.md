# 05 — 保存指南進度並核對恢復資料

Status: ready-for-agent
Type: task
Blocked by: 04
Spec: [SSH 主機操作介面與逐步建立指南](../spec.md)

## 目標與範圍

在同一瀏覽器保存指南非敏感進度；每台已加入主機可接續，另保留一筆未建立主機的草稿。不要求跨瀏覽器同步。恢復時以目前主機與金鑰資料為準，不把儲存的步驟編號當作驗證結果。

## 驗收條件

- [ ] 切換分頁或重新整理後可恢復步驟與非敏感輸入，且多台已加入主機的進度不互相覆蓋。
- [ ] 未加入主機的草稿最多一筆，建立成功後轉為該主機進度，避免再次提交而重複建立。
- [ ] 密語、私鑰與解鎖憑證不進入前端持久儲存；恢復後需要解鎖時重新引導。
- [ ] 恢復時核對主機及金鑰存在性；主機已刪除、金鑰已解除或刪除時回到可修正步驟，不重複產生金鑰。
- [ ] 主機位址、埠、登入帳號或金鑰變更使原成功結果失效並要求重新檢查。
- [ ] 歷史檢查成功附時間，不當成當前終端連線；過期回應不能把新設定標成完成。
- [ ] 持久資料無法讀取或保存時，當次指南仍可使用並明確提示無法恢復，不虛報已保存。

## 驗證

逐步重新整理、雙主機交替接續、建立後重新整理、外部刪除主機／金鑰、設定變更與舊結果、損壞或不可用儲存。檢查持久內容未包含敏感資料。
