# 05 — 保存指南進度並核對恢復資料

Status: ready-for-agent
Type: task
Blocked by: 04
Spec: [SSH 主機操作介面與逐步建立指南](../spec.md)

## 目標與範圍

在同一瀏覽器保存指南非敏感進度；每台已加入主機可接續，另保留一筆未建立主機的草稿。不要求跨瀏覽器同步。恢復時以目前主機與金鑰資料為準，不把儲存的步驟編號當作驗證結果。

## 驗收條件

- [x] 切換分頁或重新整理後可恢復步驟與非敏感輸入，多台已加入主機以獨立進度索引保存，並可從指南選擇接續。
- [x] 未加入主機的草稿最多一筆；新增成功後草稿轉為該主機進度，避免重複建立。
- [x] 密語、私鑰內容與解鎖憑證不進入前端持久儲存；只保存可恢復既有登入金鑰選擇的本機路徑，解鎖仍走主動檢查安全提示。
- [x] 恢復時核對主機及登入金鑰；外部刪除主機會清除其進度，解除登入金鑰關聯會回到金鑰步驟，不重複產生金鑰。
- [x] 主機位址、埠、登入帳號或登入金鑰路徑變更會使舊授權／成功結果失效並要求重新授權或檢查。
- [x] 歷史檢查成功附時間及「歷史檢查」說明，不當成終端連線；設定指紋不同時不恢復舊成功。
- [x] 持久資料損壞、無法讀取或寫入時顯示提示，當次指南仍可使用，不宣稱進度已保存。

## 驗證

逐步重新整理、雙主機交替接續、建立後重新整理、外部刪除主機／金鑰、設定變更與舊結果、損壞或不可用儲存。檢查持久內容未包含敏感資料。
