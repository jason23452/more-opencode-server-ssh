# 01 — 建立導覽與受管主機操作頁

Status: ready-for-agent
Type: task
Blocked by: 無
Spec: [SSH 主機操作介面與逐步建立指南](../spec.md)

## 目標與範圍

建立兩分頁的 UI 骨架，讓使用者能選取操作目標。以 `bin/sshdeck.js` 現有 UI 為起點，沿用主機資料能力，不要求導入前端框架。

- 左側依序為「主機操作」「建立指南」。
- 主機列表在操作區上方，顯示全部已加入主機；選取後顯示別名、位址與登入帳號。
- 建立指南入口與進階管理容器供後續票單整合。
- 桌面固定左側導覽，小螢幕可收合；切換分頁不以重建整頁方式破壞子功能狀態。

## 驗收條件

- [x] 兩分頁名稱與順序正確，無主機時可直接前往建立指南。
- [x] 包含設定未完成或不可連線的全部受管主機，均可選取。
- [x] 選取主機後下方顯示正確操作目標，選取本身不建立 SSH 連線。
- [x] 主機列表更新保留仍存在的選取目標與表單輸入；移除目標後不顯示可操作的過期目標。
- [x] 桌面與小螢幕導覽可用，操作有可辨識標籤與鍵盤焦點。
- [x] 保留既有功能可達性，待後續票單整合正式入口。

## 驗證

檢查空列表、多主機、選取與更新、目標被移除、兩分頁切換及桌面／窄螢幕鍵盤操作。此票驗證 UI 骨架；終端連線生命週期由 03 驗證。
