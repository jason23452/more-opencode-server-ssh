# 公鑰指南使用者名稱輸入欄位

## 摘要與目標

使用者希望在瀏覽器的 SSH 公鑰授權／撤銷指南中輸入遠端使用者名稱，並即時更新指南指令，以便設定及撤銷授權時使用正確帳號。

## 背景與需求

- 專案為 sshdeck；主機及金鑰指南由 `bin/sshdeck.js` 的本機瀏覽器介面呈現，原始指南由 `lib/ssh.js` 的 `installationGuide` 產生。
- 原指南以主機設定的 `username` 產生帳號名稱、家目錄查詢、檔案擁有者與 Docker 群組指令。
- 使用者曾在 Ubuntu 主機執行指南，後續希望移除剛新增的公鑰；對話回覆提供只比對指定兩行公鑰、保留其他 `authorized_keys` 內容的移除方式。
- 使用者接著要求將介面修改提交，已完成 commit。

## 決策與理由

- 在金鑰資訊區加入預設隱藏的「指南中的遠端使用者名稱」欄位；有指南內容時顯示，並以指南內原登入帳號初始化。
- 修改欄位時即時重繪指南，替換顯示帳號，以及以 POSIX shell 單引號跳脫後的指令帳號參數。此修改不會變更 sshdeck 保存的主機登入帳號。
- 輸入欄位只在「公鑰／撤銷指南」資訊區顯示，不會出現在主機管理首頁。

## 已完成工作與變更檔案
