# 領域文件

本專案採 single-context 布局：根目錄 `GLOSSARY.md` 與 `docs/adr/`。

## 探索程式碼前

- 閱讀根目錄的 `GLOSSARY.md`。
- 閱讀 `docs/adr/` 中與本次工作相關的決策。
- 文件不存在時直接繼續；由 `domain-modeling` 在術語或決策確立後建立。

## 使用領域詞彙

票單標題、重構提案、假設與測試名稱中的領域概念，使用詞彙表定義的術語。
若概念尚未收錄，先確認是否符合專案語言；確有缺漏時，記錄供 `domain-modeling` 補充。

## 決策衝突

提案若與既有 ADR 衝突，明確指出 ADR 編號與重新討論的理由。
