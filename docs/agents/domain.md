# 領域文件

本專案採 single-context：根目錄 `GLOSSARY.md` 與 `docs/adr/`。

## 探索前先讀取

- 閱讀根目錄 `GLOSSARY.md`。
- 閱讀 `docs/adr/` 中與本次工作相關的 ADR。
- 文件不存在時直接繼續，無須提示缺漏或預先建檔；由 `domain-modeling` 在術語或決策確立時建立。

## 使用領域詞彙

在票單標題、重構提案、假設、測試名稱等輸出中，使用 `GLOSSARY.md` 定義的術語，避開其中標示應避免的同義詞。

所需概念尚未收錄時，先確認是否誤用專案沒有的概念；若確有缺口，記錄供 `domain-modeling` 後續處理。

## 揭露 ADR 衝突

提案與既有 ADR 衝突時，明確指出 ADR 編號、衝突內容與值得重新討論的理由。
