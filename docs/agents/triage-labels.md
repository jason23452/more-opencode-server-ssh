# Triage 標籤

| 標準角色 | 本專案標籤 | 意義 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待維護者評估 |
| needs-info | needs-info | 等待回報者補充資訊 |
| ready-for-agent | ready-for-agent | 規格完整，可交由 Agent 自主執行 |
| ready-for-human | ready-for-human | 需要人工實作 |
| wontfix | wontfix | 不予處理 |

Skill 提及 triage 角色時，使用表中對應標籤，寫入票單的 `Status:`。
若需更換詞彙，修改「本專案標籤」欄。
